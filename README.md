# 🌌 Sree's Universe

> **Explore the Mind Behind the Machines.**

Sree's Universe is an interactive, cinematic digital world that tells the story of Sree through engineering, machines, creativity, and curiosity.

This repository contains the **Genesis / V0.1** foundation for the experience.

## Vision

This is not a conventional portfolio. The long-term goal is a living 3D world where the visitor explores Sree's work and interests through scenes, camera choreography, environmental storytelling, and eventually an AI guide.

## Genesis scope

V0.1 focuses on the foundations only:

- Angular application shell
- TypeScript-first architecture
- Three.js-ready world engine boundary
- Scene, camera, lighting, animation, asset, audio, and interaction contracts
- Design documentation and decision records
- CI quality gates

The first visible experience will be the cinematic arrival into Sree's Universe HQ.

## Planned stack

- Angular + TypeScript
- Three.js
- GSAP
- NestJS (later milestone)
- AI / RAG integration (later milestone)
- GitHub Actions

## Repository layout

```text
apps/
  web/          # browser experience
  api/          # future NestJS backend
packages/
  engine/       # reusable universe-engine contracts
  ui/           # shared visual primitives
  shared/       # shared types and constants
assets/         # 3D models, textures, HDR, audio
 design/        # concept art, storyboards, design language
docs/           # architecture, roadmap, ADRs
```

## North Star

> **Sree's Universe is an interactive engineering universe where software, machines, creativity, and imagination coexist. Every room tells a story. Every interaction has purpose.**
